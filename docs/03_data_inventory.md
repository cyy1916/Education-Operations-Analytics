# Phase 1: Data Audit - Data Inventory

# 数据资产盘点（Data Inventory）

## 1. 数据盘点目标（Purpose）

本阶段对当前在线语言教育业务中的现有数据文件进行整理和审计。

目前业务运营主要依赖 Excel / Google Sheets 管理不同业务环节的信息，包括：

* 市场获客；
* 客户咨询；
* 试听与等级测试；
* 学生管理；
* 课程执行；
* 教学反馈；
* 运营统计。

Data Inventory 的目标：

* 识别当前已有数据来源；
* 明确数据所属业务环节；
* 记录数据用途和维护方式；
* 分析当前数据管理中的问题；
* 为后续 Data Dictionary 和 Data Modeling 提供基础。

---

# 3. 数据来源盘点（Data Source Inventory）

# 3.1 Marketing 数据

## 3.1.1 小红书客户咨询表

### 数据用途

用于记录小红书广告投放和内容运营产生的客户咨询信息。

客户点击广告后进入咨询流程，相关信息按照日期进行记录。

### 更新方式

* 以天为单位记录；
* 不修改历史记录；
* 如果客户再次咨询或产生新的操作，则新增记录。

### 主要数据内容

| 分类   | 字段                    |
| ---- | --------------------- |
| 客户信息 | 编号、日期、客户ID、客户账号       |
| 咨询来源 | 咨询类型、广告帖子编号、引流账号/私信账号 |
| 销售跟进 | 负责人、销售名片、微信添加状态       |
| 时间信息 | 咨询时间、回复时间、响应时间        |
| 客户需求 | 关键词（零基础、小孩课程、B2等）     |
| 客户地区 | IP地区、国内/海外信息          |
| 行为数据 | 点击次数                  |

### 业务分析用途

用于分析：

* 广告带来的咨询数量；
* 客户来源；
* 销售响应效率；
* 客户添加转化情况。

# 5. 初步数据审计发现（Initial Data Audit Findings）

## 5.1 数据分散

### 发现

不同业务环节使用不同表格维护数据。

例如一个学生的信息可能分布于：

* 试听表；
* 测试表；
* 学生汇总表；
* 课程记录表。

### 影响

* 查询历史信息需要人工整理；
* 跨部门分析成本较高。

---

## 5.2 数据重复维护

### 发现

部分信息在多个文件中重复填写。

例如：

* 学生姓名；
* 老师；
* 课程类型；
* 学习状态。

### 影响

可能导致：

* 信息不同步；
* 数据版本不一致。

---

## 5.3 数据标准缺失

### 发现

部分业务分类没有统一标准。

例如：

课程形式可能出现：

* 1V1；
* 私教；
* 一对一。

### 影响

影响：

* 数据统计；
* SQL分析；
* KPI计算。

---

## 5.4 缺少部分分析字段

当前部分业务分析需要补充数据。

例如：

Retention：

* 续费时间；
* 流失原因。

Marketing：

* 广告成本；
* 渠道归因。
