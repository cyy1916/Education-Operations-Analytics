# 第一阶段：数据审计——数据资产盘点

# 数据资产盘点

## 1. 数据盘点目标

本阶段对当前在线语言教育业务中的现有数据文件进行整理和审计。

目前业务运营主要依赖 Excel / Google Sheets 管理不同业务环节的信息，包括：

* 市场获客；
* 客户咨询；
* 试听与等级测试；
* 学生管理；
* 课程执行；
* 教学反馈；
* 运营统计。

数据资产盘点的目标包括：

* 识别当前已有的数据来源；
* 明确数据所属的业务环节；
* 记录数据用途和维护方式；
* 分析当前数据管理中存在的问题；
* 为后续数据字典和数据建模提供基础。

---

# 2. 当前数据领域

根据现有业务文件，当前数据主要分为以下几个领域：

| 数据领域   | 数据内容                | 主要用途          |
| ------ | ------------------- | ------------- |
| 市场数据   | 小红书广告点击、客户咨询、帖子运营数据 | 分析客户来源和内容运营效果 |
| 销售数据   | 试听、等级测试、客户转化信息      | 管理销售转化流程      |
| 教务运营数据 | 学生信息、课程记录、教学反馈      | 管理教学交付过程      |
| 运营管理数据 | 异常事件、团队评分、工作记录      | 管理运营质量和团队表现   |

# 3. 数据来源盘点

# 3.1 市场数据

## 3.1.1 小红书客户咨询表

### 数据用途

用于记录小红书广告投放和内容运营产生的客户咨询信息。

客户点击广告后进入咨询流程，相关信息按照日期进行记录。

### 更新方式

* 以天为单位记录；
* 不修改历史记录；
* 如果客户再次咨询或产生新的操作，则新增记录。

### 主要数据内容

| 分类   | 字段                      |
| ---- | ----------------------- |
| 客户信息 | 编号、日期、客户编号、客户账号         |
| 咨询来源 | 咨询类型、广告帖子编号、引流账号 / 私信账号 |
| 销售跟进 | 负责人、销售名片、微信添加状态         |
| 时间信息 | 咨询时间、回复时间、响应时间          |
| 客户需求 | 关键词（零基础、小孩课程、B2 等）      |
| 客户地区 | 网络地址地区、国内 / 海外信息        |
| 行为数据 | 点击次数                    |

### 业务分析用途

用于分析：

* 广告带来的咨询数量；
* 客户来源；
* 销售响应效率；
* 客户添加微信后的转化情况。

# 4. 当前数据关系

根据现有业务流程，不同数据之间主要存在以下关系：

```text
小红书广告 / 帖子

        ↓

客户咨询

        ↓

试听 / 等级测试

        ↓

报名学生

        ↓

课程记录

        ↓

课程完成 / 续费
```

目前这些数据关系主要通过人工字段进行关联，例如：

* 学生姓名；
* 客户账号；
* 微信信息；
* 课程记录链接。

# 5. 初步数据审计发现

## 5.1 数据分散

### 发现

不同业务环节分别使用不同表格维护数据。

例如，一个学生的信息可能分布在：

* 试听表；
* 测试表；
* 学生汇总表；
* 课程记录表。

### 影响

可能导致：

* 查询历史信息时需要人工整理；
* 跨部门分析成本较高；
* 学生完整业务过程难以快速追踪。

---

## 5.2 数据重复维护

### 发现

部分信息需要在多个文件中重复填写。

例如：

* 学生姓名；
* 教师；
* 课程类型；
* 学习状态。

### 影响

可能导致：

* 信息更新不同步；
* 不同文件中的数据版本不一致；
* 后续统计需要额外进行人工核对。

---

## 5.3 数据标准缺失

### 发现

部分业务分类没有统一的数据标准。

例如，同一种课程形式可能出现：

* 一对一；
* 私教；
* 单人私教。

### 影响

可能影响：

* 数据统计；
* 数据查询与分析；
* 关键业务指标计算；
* 不同文件之间的数据整合。

---

## 5.4 缺少部分分析字段

### 发现

现有数据主要服务于日常运营，因此部分支持后续业务分析所需要的字段尚未被系统记录。

例如：

### 学生留存与续费分析

目前可能缺少：

* 续费时间；
* 流失时间；
* 流失原因；
* 续费次数。

### 市场分析

目前可能缺少：

* 广告成本；
* 不同渠道的投入金额；
* 客户最终来源归因；
* 单个客户的获客成本。

### 影响

这些字段的缺失会限制后续对以下问题的分析：

* 不同渠道的获客效率；
* 广告投入与转化结果之间的关系；
* 学生续费率；
* 学生流失原因；
* 不同业务环节的长期表现。

---

# 6. 数据盘点阶段总结

通过本阶段的数据资产盘点，可以初步确认：

当前业务已经积累了覆盖市场、销售、教务和运营管理等多个环节的数据，但这些数据主要围绕日常工作流程建立，因此目前仍然存在数据分散、重复维护、字段标准不统一以及部分分析字段缺失等问题。

现有数据并非无法用于分析，而是需要进一步进行结构化整理。

下一阶段需要在本次数据盘点的基础上，继续建立：

* 数据字典；
* 字段命名标准；
* 数据类型标准；
* 分类取值标准；
* 唯一标识规则；
* 数据表之间的关联关系。

这些工作将为后续的数据建模、数据清洗、数据查询分析以及数据看板设计提供基础。
