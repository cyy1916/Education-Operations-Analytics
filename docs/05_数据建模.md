# 05 数据模型设计

## 1. 建模目标

基于前期业务流程、数据资产和数据字典，对现有 Excel / Google Sheets 数据进行结构化设计。

本阶段确定：

- 核心业务实体；
- 每个实体的数据粒度；
- 主键设计；
- 主要实体关系；
- 当前数据到目标模型的映射。

---

# 2. 核心实体

| 实体 | 数据粒度 | 主键 | 主要用途 |
|---|---|---|---|
| 内部员工 | 一名员工 | employee_id | 销售、教务、运营人员管理 |
| 教师 | 一名教师 | teacher_id | 教师资源管理 |
| 运营账号 | 一个运营账号 | account_id | 内容账号管理 |
| 帖子 | 一篇帖子 | post_id | 内容运营分析 |
| 帖子指标快照 | 一篇帖子在一个统计周期的表现 | post_metric_id | 曝光、点击、转化分析 |
| 账号指标快照 | 一个账号在一个统计周期的表现 | account_metric_id | 账号增长分析 |
| 客户 | 一个唯一客户或联系人 | customer_id | 潜在客户管理 |
| 客户互动事件 | 客户的一次点击、咨询、评论或回访 | interaction_id | 客户行为分析 |
| 客户学生关系 | 一个客户与一个学生之间的关系 | customer_student_id | 家长与学生关联 |
| 试听记录 | 一次试听 | trial_id | 试听管理与转化分析 |
| 等级测试记录 | 一次等级测试 | assessment_id | 学生水平评估 |
| 学生 | 一个学生 | student_id | 学生主数据 |
| 课程产品 | 一种可销售课程产品 | course_product_id | 课程产品管理 |
| 报名记录 | 一次报名或课程购买 | enrollment_id | 报名与课时管理 |
| 私教课程 | 一个实际运行中的私教课程 | private_course_id | 一对一至一对四课程管理 |
| 私教课程成员 | 一个学生加入一个私教课程的关系 | private_member_id | 私教学生关系管理 |
| 班级 | 一个实际运行中的班课 | class_id | 班课管理 |
| 班级成员 | 一个学生加入一个班级的关系 | class_member_id | 班级学生关系管理 |
| 课程排期历史 | 一个课程在一个有效时间段内的排课规则 | schedule_id | 排课历史管理 |
| 单节课程 | 一次计划或实际发生的课程 | lesson_id | 课程执行记录 |
| 课程参与记录 | 一个学生参加一节课程的记录 | attendance_id | 出勤与课时分析 |
| 学生状态历史 | 一个学生在一段时间内的一种状态 | student_status_id | 在读、停课、完成状态分析 |
| 续费事件 | 一次续费行为 | renewal_id | 留存与续费分析 |
| 教务任务 | 一项教务工作 | task_id | 教务工作跟踪 |
| 异常事件 | 一次运营或教学异常 | issue_id | 异常分析 |

# 6. 核心建模规则

1. 客户与学生分开管理。
2. 客户主体与客户互动事件分开管理。
3. 课程产品与实际课程实例分开管理。
4. 私教课程与班课分别建模。
5. 一对二、一对三、一对四通过私教课程成员表管理。
6. 班级学生通过班级成员表管理。
7. 单节课程与学生通过课程参与记录关联。
8. 私教排课调整通过课程排期历史保存。
9. 在读、停课、已完成通过学生状态历史管理。
10. 续费作为独立事件保存。
11. 教务任务与学生基本信息分离。
12. 异常反馈作为独立事件保存。
13. 中文星期、西语星期、英语星期等派生字段不作为核心事实重复存储。
14. 月度学生数、转化率、开班率、环比和同比由底层业务数据计算。
